# Camp Colt Staff Directives & Playbooks (`rigs/a-staff`)

This repository contains operational policies, standard operating procedures (SOPs), playbooks, and organizational reference materials for autonomous agents operating in Camp Colt.

## Repository Structure

- **[`directives/`](directives/)**: Core policies, guidelines, and operating standards:
  - [`COMMANDERS_PLANNING_GUIDANCE.md`](directives/COMMANDERS_PLANNING_GUIDANCE.md): Foundational planning guidance by Nick Chalko.
  - [`STYLE_GUIDE_AND_LEXICON.md`](directives/STYLE_GUIDE_AND_LEXICON.md): Technical communication guidelines and terminology standards.
  - [`SOP_OPERATIONAL_CADENCE_AND_PLANNING_HORIZONS.md`](directives/SOP_OPERATIONAL_CADENCE_AND_PLANNING_HORIZONS.md): Planning cycles, task horizons, and 14-day completion gates.
  - [`SOP_OPERATIONS_WATCH_AND_STAGNATION_DETECTION.md`](directives/SOP_OPERATIONS_WATCH_AND_STAGNATION_DETECTION.md): Operations watch patrols and stall-mitigation protocols.
  - [`SOP_SIGNAL_COMMUNICATIONS_WATCH_AND_PRIORITY_DELIVERY.md`](directives/SOP_SIGNAL_COMMUNICATIONS_WATCH_AND_PRIORITY_DELIVERY.md): Priority message delivery, routing, and notifications.
  - [`SOP_STAFF_ACTION_AND_AAR_WORKFLOW.md`](directives/SOP_STAFF_ACTION_AND_AAR_WORKFLOW.md): Completed staff work and After Action Review (AAR) workflows.
  - [`SOP_WEEKLY_TASK_FRICTION_AAR.md`](directives/SOP_WEEKLY_TASK_FRICTION_AAR.md): Weekly task friction and process improvement review.
  - [`REQ_CROSS_REPO_GIT_CLEANLINESS_AUDIT.md`](directives/REQ_CROSS_REPO_GIT_CLEANLINESS_AUDIT.md): Cross-repository hygiene and audit standards.
- **[`playbooks/`](playbooks/)**: Execution playbooks and operational procedures:
  - [`ROSTER_STAFF_BILLETS_AND_IDENTITIES.md`](playbooks/ROSTER_STAFF_BILLETS_AND_IDENTITIES.md): Staff role specifications, session aliases, and execution providers.
  - [`SOP_GIT_WORKTREE_CLEANLINESS.md`](playbooks/SOP_GIT_WORKTREE_CLEANLINESS.md): Git worktree management and workspace cleanliness.
  - [`SOP_S3_TACTICAL_WATCH_CADENCE.md`](playbooks/SOP_S3_TACTICAL_WATCH_CADENCE.md): Operations watch sampling cadence and stall escalation.
  - [`SOP_S4_REPOSITORY_PROVISIONING.md`](playbooks/SOP_S4_REPOSITORY_PROVISIONING.md): Repository provisioning, quotas, and branch protection.
  - [`models/`](playbooks/models/): Model specifications and performance dossiers.
- **[`references/`](references/)**: Baseline reference manuals (e.g. MCTP 3-30A, MCRP 3-10A.1).

## Style & Standards

All documentation must adhere to [`directives/STYLE_GUIDE_AND_LEXICON.md`](directives/STYLE_GUIDE_AND_LEXICON.md):

- Keep documentation professional, direct, and free of theatrical jargon.
- Emphasize empirical evidence, reproducible configs, and telemetry over assertions.
- Maintain consistent copyright and attribution.
