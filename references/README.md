## How to Add a Reference

1. Place the extracted/summarised content in this directory as
   `<SOURCE_NAME>_extract.md`
2. Always include:
   - Full title and publication date
   - Official source URL (even if access-restricted)
   - Local copy path (if file is stored offline in `~/Downloads` or similar)
   - Verbatim key passages with page references
   - A "Relationship to Suitcase AI" section mapping doctrine to architecture
3. Link the new file from this README
